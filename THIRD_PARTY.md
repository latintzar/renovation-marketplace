# Third-party terms

The root MIT licence covers Peter Neyra's original code, documentation and newly authored fictional samples. Installed dependencies retain their own licences. Package manifests and `pnpm-lock.yaml` identify the exact frontend dependency graph; Python manifests identify the retained backend packages.

| Material | Source and terms |
| --- | --- |
| Source Sans 3 | Adobe; SIL Open Font License 1.1. [Included licence](apps/scope/product/web/public/fonts/SourceSans3-OFL.txt) |
| Playfair Display | Claus Eggers Sørensen; SIL Open Font License 1.1. [Included licence](apps/scope/product/web/public/fonts/PlayfairDisplay-OFL.txt) |
| Lucide icons | `lucide-react`; ISC licence in the installed package |
| Mapbox GL and map services | `mapbox-gl`; its package licence and [Mapbox terms](https://www.mapbox.com/legal/tos). Configure a recipient account and token for connected maps. |
| Stripe, Apple Pay, Google Pay, WhatsApp and other integration names/marks | Their owners' trademarks and service terms. Integration code preserves the original product context. |
| Optional Hermes runtime | Separate upstream installation and licence. Its historical vendor checkout/version was outside the recovered tracked tree. [Status](docs/status.md). |

Fonts are self-hosted with source URLs, upstream Git blob identifiers and SHA-256 checksums in [font provenance](apps/scope/product/web/public/fonts/provenance.json). Source attribution and legal notices in individual files remain in place. The release omits unverified photographs, videos and a borrowed texture; [asset provenance](provenance/asset-omissions.json) records the change.

The retained profile-import script contains an attributed historical public directory example. Its business facts, short review excerpt, source link and platform mark keep that original context; the newly authored attachment is explicitly a fictional record.
